# 後臺執行

> 本文件由簡體中文版經 OpenCC 簡繁轉換產生，用語以台灣習慣為準；內容如有差異，請以簡體中文版為準。

想在小助手執行任務時繼續使用電腦，可以從下面三種方式中選擇：

| 方式 | 適用 | 對你的鍵鼠 | 配置難度 |
|------|------|-----------|---------|
| Windows 後臺模式（推薦） | Windows 本地遊戲 | 點選、拖動和滾輪不移動系統滑鼠 | 設定裡切換即可 |
| 雲·星穹鐵道 | 雲遊戲 | 不佔用 | 設定裡開啟 |
| 遠端本地多使用者桌面（進階） | Windows 本地遊戲 | 不佔用當前桌面 | 需要修改系統元件 |

## Windows 後臺模式（推薦）

遊戲視窗留在其他視窗後面，小助手通過視窗訊息操作遊戲，任務執行時你可以繼續使用電腦。預設仍為前臺模式，需要手動開啟。

### 開啟方式

在 `設定 → 雜項 → 本地操作模式` 中選擇“後臺”，閱讀並確認彈出的說明後，下次啟動任務時生效。自動對話需要關閉後重新開啟才會應用。

也可以直接修改配置檔案：

```yaml
local_control_mode: background
```

`background_mouse_protection` 仍可留在舊配置裡，但已經不起作用：後臺操作不再鎖定或借用系統滑鼠。

雲遊戲使用自己的輸入方式，不受此設定影響。

### 使用前提

- 遊戲視窗可以留在其他視窗之後，但**不能最小化**：最小化的視窗無法截圖，也不會處理輸入。
- 鎖屏或 UAC 等安全桌面不會阻止視窗訊息本身。若這段時間遊戲把游標鎖到視窗中央，暫時可能無法把游標放回去，解鎖後下一次操作會再嘗試歸還。
- 遊戲使用管理員許可權執行時，小助手也需要相應許可權（正常啟動的小助手會自動申請）。
- 後臺模式強制使用視窗截圖；視窗截圖失敗時停止識別，不回退到可能包含其他應用的桌面截圖。

### 對滑鼠和鍵盤的影響

做法與 BetterGI 的後臺通道相同：把客戶區座標放進視窗訊息，發給遊戲視窗控制代碼，不呼叫 `SetCursorPos`，也不把遊戲切到前臺。你可以繼續移動自己的滑鼠。

- **點選、懸停和拖動**傳送 `WM_MOUSEMOVE`、`WM_LBUTTONDOWN`、`WM_LBUTTONUP`。落點是訊息裡的客戶區座標，不是系統游標的位置。
- **滾輪**傳送 `WM_MOUSEWHEEL`，螢幕座標用虛擬指標換算，不把游標挪到遊戲上，也不臨時搶前臺。
- **按鍵**仍用 `WM_KEYDOWN` / `WM_KEYUP`，不搶鍵盤焦點。遊戲不在前臺時，按鍵、點選和滾輪之前會補發 `WM_ACTIVATE`，否則 Unity 會丟掉這次輸入。
- **大世界視角**下，遊戲可能在這次“自己被啟用”的短暫時間裡把游標鎖到視窗中央。指令碼若觀察到這次鎖定，會在操作結束後把游標歸還；它不會為了點選把游標搬到按鈕上。選單介面通常不會鎖游標，點選時系統滑鼠保持不動。
- 不帶座標的普通攻擊在識別到視角鎖定時，於鎖定點按下、釋放，不復用上一張介面的點選位置，也不移動系統游標。
- 你正在使用滑鼠時，點選和拖動不再等待，也不會再彈出“等待滑鼠空閒”或“滾輪需切到前臺”。

### 視窗狀態變化

- **切換視窗**：把遊戲切到前臺或切到其他視窗都是正常操作，不會報錯結束任務，也不會為了滾輪或點選把焦點搶回來。若恰好處於輸入過程中，會先釋放本次按鍵和滑鼠，再交給任務重新識別遊戲畫面；已經發出的按鍵、文本、點選和拖動不會自動重放。
- **最小化或暫時不可見**：不傳送任何輸入，截圖和輸入最多等待 60 秒並提示還原遊戲視窗；還原後自動繼續（等待期間被擱置的那次輸入按未完成返回，不會補發），超時則停止任務並寫明原因（例如“遊戲視窗已最小化（已等待 60 秒）”）。同一段不可用期間只等待一次，暫停期間不計入等待時間。程式不會自動還原或啟用遊戲視窗。
- **遊戲程序退出**：立即報告“遊戲程序已退出”，不再等待，也不會提示“請恢復視窗”。在啟動遊戲階段與前臺模式一樣關閉遊戲後重啟；任務進行中按普通錯誤結束。
- **找不到遊戲視窗但程序仍在**（例如遊戲正在啟動或重建視窗）：同樣等待最多 60 秒，超時按普通錯誤處理。
- **遊戲忙於載入**：滑鼠訊息在 0.5 秒內未被遊戲處理時，釋放本次輸入並按未完成返回，由任務重新確認介面，不會因此結束任務。
- 輸入過程中視窗移動、改變大小或座標超出遊戲畫面時，同樣釋放輸入並按未完成返回。

“未完成”只表示本次輸入沒有完整發出；已經完整發出、只是在收尾等待時遇到切窗或暫停的操作仍按成功返回，避免任務把已經生效的點選或按鍵再執行一次。

### 暫停與停止

暫停、停止會先釋放後端持有的按鍵和滑鼠，再回執狀態。暫停恢復後不重放已經中斷的長按或拖動，請確認當前介面再繼續。圖形介面停止任務時先發送停止指令並等待“已釋放輸入”的回執，再結束程序；未在限時內收到回執時，仍使用原有強制結束方式並記錄日誌。命令列 `--control <執行編號> stop` 使用同一套指令。

### 已知限制

- 啟動器以及獨立執行的鋤大地、第三方模擬宇宙等程式不會因此獲得後臺能力，仍需按這些程式的要求在前臺執行。
- **獨佔全屏**、部分反作弊，以及只看真實游標（`GetCursorPos` / Raw Input）而不看視窗訊息座標的鏡頭，可能點不中或滾不動。這時請改回前臺模式。BetterGI 的後臺通道同樣不支援相對移動；本助手的滾輪多發了 `WM_MOUSEWHEEL`，遊戲若忽略該訊息，對應步驟也需要前臺。
- 前臺模式仍使用系統鍵鼠，會移動真實游標。雲遊戲走自己的輸入，不受本地後臺模式影響。
- 文本輸入會在同一啟用會話中重新點選最近定位的輸入框，再發送字元；不支援輸入法候選，也不支援在任意編輯器中追加輸入。
- 貨幣戰爭的獎勵球使用短段掃動，每段結束釋放滑鼠；某一步未完成時保留當前階段，下一輪重新檢查，不直接進入購買或出戰。
- 遇到識別或操作異常時，可以先切回前臺模式確認問題是否與後臺模式有關，再附上日誌反饋。

## 雲·星穹鐵道

開啟 `雲·星穹鐵道` 後，清體力、每日實訓、貨幣戰爭、差分宇宙等任務不再要求固定視窗，支援後臺執行，也可以開啟無視窗模式；鋤大地和模擬宇宙仍需要保持前臺全屏。

雲遊戲不依賴本機遊戲視窗，也可以在 macOS、Linux、[Docker](/assets/docs/Docker.md) 和 [Termux 安卓](/assets/docs/Termux.md) 上執行，開啟方式見 [使用教程](/assets/docs/Tutorial.md)。

## 遠端本地多使用者桌面（進階）

> 在同一臺電腦上（不需要第二臺電腦）通過本機遠端桌面再登入一個 Windows 使用者會話，讓遊戲和小助手在那個會話裡以前臺模式執行，完全不佔用你當前桌面的鍵鼠。需要給系統打補丁以允許多使用者同時登入，配置較複雜，系統更新後補丁也可能失效。一般情況下建議優先使用 Windows 後臺模式。

 * 模擬器執行擁有卡頓，效能消耗大等諸多缺點，在電腦上直接執行的效能消耗要小於模擬器
 * 我們推薦使用 Windows 自帶的遠端桌面服務
 * Windows 開啟遠端桌面多使用者教程：
   * [詳細教程 by_Rin](https://www.bilibili.com/read/cv24286313/)（⭐推薦⭐）
   * [RDPWrap 方法](https://blog.sena.moe/win10-multiple-RDP/)
   * [修改檔案方法](https://www.wyr.me/post/701)
 * [詳細教程 by_Rin](https://www.bilibili.com/read/cv24286313/) 中所有相關檔案：[下載連結](https://github.com/CHNZYX/asu_version_latest/releases/download/RDP/LocalRemoteDesktop1.191_by_lin.zip)
   * 備用連結
     * [百度網盤](https://pan.baidu.com/s/13aoll4n1gmKlPT9WwNYeEw?pwd=jbha) 提取碼：jbha
     * [GitHub映象](https://github.kotori.top/https://github.com/CHNZYX/asu_version_latest/releases/download/RDP/LocalRemoteDesktop1.191_by_lin.zip)

小助手在遠端會話裡執行時，請保持遠端桌面連線，不要斷開會話。預設情況下，遠端桌面視窗最小化後遠端會話會停止繪製畫面，可能導致截圖失敗；需要最小化時，可在你當前使用者的登錄檔 `HKEY_CURRENT_USER\Software\Microsoft\Terminal Server Client` 下新建 DWORD 值 `RemoteDesktop_SuppressWhenMinimized`，資料設為 `2`，然後重新開啟遠端桌面連線。

### 對於 Windows 11 使用者

在 [詳細教程 by_Rin](https://www.bilibili.com/read/cv24286313/) 中提到的 `SuperRDP` 軟體可能已無法使用，建議改用 [TermsrvPatcher](https://github.com/fabianosrc/TermsrvPatcher)。如果你在國內使用，可以通過備用連結下載：[藍奏雲](https://wwsj.lanzout.com/i4V8u2np8dna)。

**注意：** 此方法僅實現了[詳細教程 by_Rin](https://www.bilibili.com/read/cv24286313/)中`4. 多使用者同時登陸補丁`的功能，其餘步驟請繼續按照原教程進行。

**使用方法：**

1. 使用 `git clone` 克隆倉庫，或直接下載壓縮包。
2. 下載完成後，解壓壓縮包，找到 `TermsrvPatcher.ps1` 檔案，右鍵點選選擇“執行”，指令碼將自動完成所有操作。

此外，如果你希望手動修改檔案，可以參考部落格文章：[修改檔案方法](https://www.wyr.me/post/701)。不過需要注意的是，該部落格中的部分操作在 Windows 11 上可能不適用，具體如下：

- **在 Windows 11 中需搜尋的字串（正則）：**
   `39 81 3C 06 00 00 0F (?:[0-9A-F]{2} ){4}00`（實際操作中，僅需搜尋`39 81 3C 06 00 00 0F`即可，剩下的兩個16進位制數符合正規表示式再進行修改）
- **替換為的字串：**
   `8B 81 38 06 00 00 39 81 3C 06 00 00 75`
